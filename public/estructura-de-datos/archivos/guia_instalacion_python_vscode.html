🎯 Introducción

Bienvenido a esta guía completa para la instalación de Python y Visual Studio Code. Esta guía te llevará paso a paso a través del proceso de instalación y configuración de ambas herramientas.

¿Qué es Python?

Python es un lenguaje de programación interpretado, de alto nivel y de propósito general. Es conocido por su sintaxis clara y legible, lo que lo hace ideal tanto para principiantes como para desarrolladores experimentados.

¿Qué es Visual Studio Code?

Visual Studio Code (VSCode) es un editor de código fuente gratuito y de código abierto desarrollado por Microsoft. Es altamente personalizable y cuenta con excelente soporte para Python.

⚠️ Importante: Sigue todos los pasos en orden para evitar problemas durante la instalación.

💻 Requisitos del Sistema

Requisitos Mínimos:

Sistema Operativo:
  • Windows 10 o superior
  • macOS 10.14 o superior
  • Linux (Ubuntu 16.04+, Debian 9+, CentOS 7+)
Hardware:
  • RAM: 4 GB mínimo (8 GB recomendado)
  • Espacio en disco: 2 GB disponible
  • Procesador: 1.6 GHz o superior
Permisos:
  • Permisos de administrador para la instalación
  • Conexión a internet activa

🐍 Instalación de Python

Paso 1: Descarga Python

1 Visita el sitio oficial: Ve a python.org/downloads
2 Descarga la versión más reciente: Haz clic en el botón de descarga para tu sistema operativo.
⬇️ Descargar Python

Paso 2: Instalación en Windows

3 Ejecuta el instalador: Haz doble clic en el archivo descargado.
4 Configuración importante:
  • ✅ Marca "Add Python to PATH"
  • ✅ Selecciona "Install for all users" (recomendado)
  • ✅ Haz clic en "Install Now"
⚠️ Muy Importante: No olvides marcar "Add Python to PATH" durante la instalación. Esto es crucial para poder usar Python desde la línea de comandos.

Paso 3: Instalación en macOS

5 Abre el archivo .pkg y sigue las instrucciones del instalador.

Paso 4: Instalación en Linux

6 Ubuntu/Debian:
sudo apt update
sudo apt install python3 python3-pip

✅ Verificación de Python

Verificar la instalación:

1 Abre la línea de comandos:
  • Windows: Presiona Win + R, escribe "cmd" y presiona Enter
  • macOS: Presiona Cmd + Space, escribe "Terminal"
  • Linux: Presiona Ctrl + Alt + T
2 Ejecuta el comando:
python --version

o en algunos sistemas:

python3 --version
3 Verifica pip:
pip --version
✅ Éxito: Si ves la versión de Python y pip, la instalación fue exitosa.

💻 Instalación de Visual Studio Code

Paso 1: Descarga VSCode

1 Visita el sitio oficial: Ve a code.visualstudio.com
2 Descarga para tu sistema:
⬇️ Descargar VSCode

Paso 2: Instalación

3 Windows:
  • Ejecuta el archivo .exe descargado
  • Acepta los términos de licencia
  • Selecciona la carpeta de instalación
  • ✅ Marca "Add to PATH"
  • ✅ Marca "Create a desktop icon"
4 macOS:
  • Abre el archivo .zip descargado
  • Arrastra Visual Studio Code a la carpeta Applications
5 Linux:
# Para Ubuntu/Debian (.deb)
sudo dpkg -i code_*.deb
sudo apt-get install -f

⚙️ Configuración de VSCode para Python

Paso 1: Instalar la extensión de Python

1 Abre VSCode y haz clic en el icono de extensiones (cuadrado con cuadrados) en la barra lateral.
2 Busca "Python" en el campo de búsqueda.
3 Instala la extensión oficial: Busca "Python" by Microsoft e instálala.

Paso 2: Configurar el intérprete de Python

4 Presiona Ctrl+Shift+P (Cmd+Shift+P en macOS) para abrir la paleta de comandos.
5 Escribe "Python: Select Interpreter" y selecciona la opción.
6 Selecciona la versión de Python que instalaste.

Paso 3: Extensiones recomendadas

7 Instala estas extensiones útiles:
  • Python - Soporte completo para Python
  • Python Docstring Generator - Genera documentación automática
  • Python Indent - Ayuda con la indentación
  • Bracket Pair Colorizer - Colorea los paréntesis

🎉 Tu Primer Programa en Python

Paso 1: Crear un nuevo archivo

1 Abre VSCode y presiona Ctrl+N (Cmd+N en macOS) para crear un nuevo archivo.
2 Guarda el archivo: Presiona Ctrl+S (Cmd+S en macOS) y guárdalo como "mi_primer_programa.py"

Paso 2: Escribir código Python

3 Escribe el siguiente código:
# Mi primer programa en Python
print("¡Hola, mundo!")
print("Python está funcionando correctamente")

# Variables y operaciones básicas
nombre = "Estudiante"
edad = 20
print(f"Hola {nombre}, tienes {edad} años")

# Operaciones matemáticas
a = 10
b = 5
suma = a + b
print(f"La suma de {a} + {b} = {suma}")

Paso 3: Ejecutar el programa

4 Método 1 - Desde VSCode:
  • Haz clic derecho en el archivo y selecciona "Run Python File in Terminal"
  • O presiona F5 para ejecutar con el depurador
5 Método 2 - Desde la terminal:
python mi_primer_programa.py
✅ ¡Felicitaciones! Si ves la salida del programa, has configurado exitosamente Python y VSCode.

🔧 Solución de Problemas Comunes

Problema 1: "Python no se reconoce como comando"

Solución:
  • Reinstala Python y asegúrate de marcar "Add Python to PATH"
  • O agrega manualmente Python al PATH del sistema

Problema 2: VSCode no encuentra Python

Solución:
  • Abre la paleta de comandos (Ctrl+Shift+P)
  • Busca "Python: Select Interpreter"
  • Selecciona la ruta correcta de Python

Problema 3: Errores de permisos en Linux/macOS

Solución:
# Para pip
python3 -m pip install --user nombre_paquete

# Para instalación de Python
sudo apt install python3-pip
💡 Consejo: Si encuentras otros problemas, revisa la documentación oficial o busca ayuda en foros especializados.
