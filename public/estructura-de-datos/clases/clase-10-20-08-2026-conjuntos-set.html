Indicaciones Generales:Comprender el funcionamiento de los conjuntos (set) en Python como una estructura de datos utilizada para almacenar elementos únicos y realizar operaciones de pertenencia y combinación de conjuntos, mediante la aplicación de sus principales características y métodos en situaciones relacionadas con el desarrollo de software.

Competencias a Desarrollar

  • Implementar conjuntos (set) en Python para almacenar y manipular colecciones de elementos únicos, aplicando operaciones de creación, inserción, eliminación, pertenencia y unión en la solución de problemas relacionados con el desarrollo de software.
