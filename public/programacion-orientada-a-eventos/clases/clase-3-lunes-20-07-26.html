¿Qué es TypeScript?

📌 Definición

TypeScript es un superset de JavaScript que añade tipado estático y otras características modernas. Fue desarrollado por Microsoft para ayudar a construir aplicaciones a gran escala.

🎯 ¿Por qué usarlo?

  • Tipado estático: Detecta errores en tiempo de compilación.
  • Autocompletado: Mejora la experiencia de desarrollo.
  • Mantenibilidad: Código más predecible y fácil de entender.
  • POE: Permite tipar eventos, emisores y manejadores.

💡 Para POE: TypeScript nos permite definir tipos de eventos, estructuras de datos y contratos entre emisores y oyentes.

📦

Variables y Tipos Básicos

Las variables en TypeScript son contenedores que almacenan valores. TypeScript nos permite declarar explícitamente el tipo de dato que contendrán.

🔢 Números

number

Enteros y decimales

📝 Texto

string

Cadenas de texto

⚖️ Booleano

boolean

true / false

📌 Declaración de variables

let nombre: string = "Ana";
let edad: number = 25;
let esEstudiante: boolean = true;
const PI: number = 3.1416;

Diferencia: let permite reasignación, const no. TypeScript infiere tipos automáticamente.

🔀

Condicionales

Permiten tomar decisiones en el código. Ejecutan diferentes bloques según una condición.

🔹 if / else

Ejecuta un bloque si la condición es verdadera.

También puede tener else if y else.

🔹 Operador Ternario

Forma compacta de escribir un if/else.

Sintaxis: condición ? valor1 : valor2

💡 Para POE: Los condicionales son útiles para validar eventos y decidir qué acción tomar según el tipo de evento o sus datos.

🔄

Ciclos

Permiten repetir un bloque de código varias veces. Son esenciales para procesar colecciones de datos.

for

Repite con un contador

Ideal para arreglos indexados

while

Repite mientras se cumpla

Útil cuando no se sabe cuántas

forEach

Itera sobre arreglos

Muy usado en TypeScript

💡 Para POE: Los ciclos son útiles para procesar listas de eventos o escuchar múltiples fuentes de eventos.

📋

Arreglos

Los arreglos son colecciones ordenadas de elementos del mismo tipo. Se pueden declarar de dos formas:

🔹 Sintaxis con []

let numeros: number[] = [1, 2, 3];

🔹 Sintaxis con Array<T>

let nombres: Array<string> = ["Ana", "Luis"];

💡 Para POE: Los arreglos se usan para almacenar listas de eventos, colas de mensajes y listados de oyentes.

📐

Modelos o Plantillas

Los modelos definen la estructura que deben tener los objetos. En TypeScript se usan interfaces y type aliases.

🔹 Interface

Define un contrato que un objeto debe cumplir.

interface Usuario {
  nombre: string;
  edad: number;
  email?: string; // opcional
}

🔹 Propiedades opcionales

Con ? se indica que la propiedad no es obligatoria.

💡 Ejemplo: email?: string significa que puede o no estar presente.

💡 Para POE: Los modelos son esenciales para definir la estructura de los eventos, los datos que transportan y los contratos entre emisores y oyentes.

⚡

Funciones

Las funciones son bloques de código que se ejecutan cuando son llamadas. Pueden recibir parámetros y devolver resultados.

🔹 Función tradicional

Se declara con function y tiene un nombre.

function sumar(a: number, b: number): number {
  return a + b;
}

🔹 Función flecha (Arrow)

Sintaxis moderna y más compacta.

const sumar = (a: number, b: number): number => a + b;

💡 Para POE: Las funciones son los manejadores de eventos (handlers). Se pasan como callbacks a los emisores.

🏗️

Clases y Objetos

Las clases son plantillas para crear objetos. Encapsulan datos (propiedades) y comportamiento (métodos).

🔹 Clase

class Persona {
  constructor(public nombre: string, public edad: number) {}
  saludar(): void {
    console.log(`Hola, soy ${this.nombre}`);
  }
}

🔹 Objeto

Instancia de una clase. Contiene datos y puede ejecutar métodos.

const ana = new Persona("Ana", 25);
ana.saludar(); // "Hola, soy Ana"

💡 Para POE: Las clases se usan para crear emisores de eventos, manejadores y sistemas completos basados en eventos.

📋 Registro de Asistencia a Eventos

Enunciado: Crea un molde para registrar a los asistentes de un seminario de la universidad. El nombre y la carrera son obligatorios, pero el correo electrónico y el número de asiento asignado son opcionales. Crea dos asistentes (uno con datos completos y otro sin los opcionales) y usa condicionales para imprimirlos de forma limpia.

interface Asistente {
  nombre: string;
  carrera: string;
  email?: string;
  asiento?: number;
}
