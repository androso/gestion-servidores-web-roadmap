FUNDAMENTOS

⚙️

Algoritmo

Secuencia de pasos lógicos y finitos para resolver un problema específico. La base de toda la programación.

💡 Búsqueda binaria, ordenamiento.
📦

Estructura de Datos

Forma de organizar y almacenar datos para su uso eficiente. Arreglos, listas, árboles, grafos.

📌 Arrays, Listas, Pilas, Colas.
🧠

Lógica de Programación

Capacidad de estructurar el pensamiento para resolver problemas mediante instrucciones secuenciales y condicionales.

🔹 Secuencia, Decisión, Iteración.
🔄

SDLC

Software Development Life Cycle: proceso que sigue un software desde su concepción hasta su retiro.

📌 Análisis, Diseño, Desarrollo, Pruebas.
⚡

Complejidad Algorítmica

Medida de eficiencia de un algoritmo en tiempo y memoria. Notación Big O.

📊 O(1), O(log n), O(n), O(n²).
📐

Abstracción

Principio que oculta detalles complejos y muestra solo la funcionalidad esencial.

🎯 POO, APIs, Interfaces.
📝

Pseudocódigo

Representación de un algoritmo en un lenguaje intermedio entre el natural y el código, para planificar la solución antes de programar.

📌 Escritura en español simplificado.
📊

Diagrama de Flujo

Representación gráfica de un algoritmo usando símbolos estandarizados para visualizar el flujo de ejecución.

🔹 Inicio/Fin, Decisión, Proceso, Datos.
🧩

Modularización

Técnica de dividir un programa en partes más pequeñas e independientes (módulos) para facilitar desarrollo y mantenimiento.

📌 Beneficios: Reutilización, Escalabilidad.
🎯

Requerimiento

Necesidad que debe cumplir un sistema. Se dividen en funcionales (qué hace) y no funcionales (cómo lo hace).

📌 Especificación, Validación, Trazabilidad.
📋

Caso de Uso

Descripción de una interacción entre un actor (usuario) y el sistema para lograr un objetivo específico.

📌 Diagramas UML, Escenarios, Actores.
📊

Métrica de Software

Medida cuantitativa de atributos del software como complejidad, líneas de código, acoplamiento, cohesión.

📌 LOC, Complejidad Ciclomática, Cohesión.
🔁

Iteración

Cada ciclo de repetición en un proceso de desarrollo, donde se construye una versión incremental del software.

📌 Sprint, Incremento, Versión.
🧮

Recursión

Técnica donde una función se llama a sí misma para resolver problemas dividiéndolos en subproblemas más pequeños.

📌 Factorial, Fibonacci, Torres de Hanoi.
📚

Paradigma de Programación

Estilo o enfoque fundamental de programación: imperativo, declarativo, funcional, orientado a objetos.

📌 POO, Funcional, Lógico, Estructurado.
🛠️

Ingeniería de Software

Aplicación de principios de ingeniería al desarrollo de software para lograr sistemas confiables y eficientes.

📌 Procesos, Métodos, Herramientas.
📋

Documentación Técnica

Conjunto de documentos que describen el software, su arquitectura, API, instalación y uso para facilitar mantenimiento.

📌 Manuales, Javadoc, Swagger.
🔧

Refactorización

Proceso de reestructurar código existente sin cambiar su comportamiento externo para mejorar su calidad, legibilidad y mantenibilidad.

📌 Extraer método, Renombrar, Simplificar.
🔄

Deuda Técnica

Consecuencia de tomar atajos en el desarrollo que generan código subóptimo, requiriendo trabajo futuro para corregirlo.

📌 Refactorización, Testing, Mantenimiento.
📊

KPI (Indicador Clave)

Métrica utilizada para evaluar el éxito de un proyecto o proceso, como tiempo de respuesta, tasa de errores, velocidad de desarrollo.

📌 Lead Time, Throughput, MTBF.

PROGRAMACIÓN ORIENTADA A OBJETOS

🏷️

Clase

Plantilla que define atributos y métodos comunes a un grupo de objetos. Es el molde para crear instancias.

📌 class Auto { ... }
🎯

Objeto

Instancia concreta de una clase, con sus propios valores de atributos. Tiene estado, comportamiento e identidad.

📌 var miAuto = new Auto();
📋

Atributo

Dato que describe el estado de un objeto. Características que definen a la clase y sus instancias.

📌 nombre, edad, saldo.
⚙️

Método

Acción que puede ejecutar un objeto. Son funciones definidas dentro de una clase.

📌 calcular(), mostrar(), modificar().
🔗

Herencia

Mecanismo que permite que una clase hija herede atributos y métodos de una clase padre. Promueve reutilización.

📌 class Perro extends Animal.
🛡️

Encapsulamiento

Principio que oculta los detalles internos de un objeto y protege sus datos, exponiendo solo lo necesario.

📌 private, public, protected.
🎭

Polimorfismo

Capacidad de un objeto de tomar muchas formas. Un mismo método se comporta diferente según el contexto.

📌 Sobrecarga y sobreescritura.
🏗️

Constructor

Método especial que se ejecuta al crear un objeto de una clase. Inicializa los atributos.

📌 constructor(nombre, edad) { ... }
🗑️

Destructor

Método que se ejecuta cuando un objeto es destruido o sale de su ámbito, liberando recursos.

📌 ~Persona() en C++.
🎨

Interfaz

Contrato que define métodos que una clase debe implementar, sin proporcionar su implementación.

📌 interface Figura { calcularArea(); }
📐

Clase Abstracta

Clase que no puede ser instanciada directamente, diseñada para ser heredada por otras clases.

📌 abstract class Animal { ... }
🔒

Modificadores de Acceso

Palabras clave que controlan la visibilidad de atributos y métodos: public, private, protected, package.

📌 public, private, protected.
📦

Paquete (Package)

Mecanismo para organizar clases relacionadas en grupos lógicos, facilitando la gestión de proyectos grandes.

📌 import java.util.*;
🔁

Sobrecarga (Overloading)

Definir múltiples métodos con el mismo nombre pero diferentes parámetros (tipo o cantidad).

📌 sumar(int a, int b) vs sumar(double a, double b).
📝

Sobrescritura (Overriding)

Redefinir un método heredado de una clase padre en una clase hija para proporcionar una implementación específica.

📌 @Override en Java.
🗂️

Colección (Collection)

Estructura de datos que agrupa múltiples elementos en una sola unidad. Listas, conjuntos, mapas.

📌 ArrayList, HashSet, HashMap.
🎯

Patrón de Diseño

Solución reutilizable para problemas comunes en diseño de software. Ejemplos: Singleton, Factory, Observer.

📌 Singleton, Factory, MVC.
🔗

Composición vs Agregación

Relaciones entre objetos. Composición: parte-todo fuerte (el todo crea y destruye a las partes). Agregación: relación más débil.

📌 Auto tiene Motor (composición), Auto tiene Pasajero (agregación).

ESTRUCTURAS DE CONTROL

🔀

Condicional if

Estructura que ejecuta un bloque de código solo si se cumple una condición booleana.

📌 if (edad >= 18) { ... }
🔀

if-else

Estructura que permite elegir entre dos caminos según una condición.

📌 if (nota >= 6) { ... } else { ... }
🔀

elif (else-if)

Permite evaluar múltiples condiciones en secuencia, ejecutando el primer bloque verdadero.

📌 if (a) { ... } elif (b) { ... } else { ... }
🔀

Switch / Case

Estructura que evalúa una expresión y ejecuta diferentes bloques según el valor.

📌 switch(opcion) { case 1: ... }
🔄

Ciclo for

Bucle que repite un bloque un número conocido de iteraciones, usando un contador.

📌 for (i=0; i<10; i++) { ... }
🔄

Ciclo while

Bucle que repite un bloque mientras se cumpla una condición. Se evalúa al inicio.

📌 while (x < 10) { ... }
🔄

do-while

Bucle que ejecuta el bloque al menos una vez, luego evalúa la condición al final.

📌 do { ... } while (x < 10);
⏸️

break

Sentencia que sale inmediatamente de un bucle o estructura switch.

📌 break;
⏩

continue

Sentencia que salta a la siguiente iteración de un bucle, omitiendo el resto del código.

📌 continue;
🔁

Bucle Infinito

Ciclo que nunca termina porque su condición siempre es verdadera. Puede causar bloqueo del programa.

⚠️ while (true) { ... }
🔄

Ciclo Anidado

Un bucle dentro de otro bucle. El bucle interno se completa por cada iteración del externo.

📌 for (i) { for (j) { ... } }
📊

Operador Ternario

Condicional en una sola línea que asigna un valor según una condición: condición ? valor_si : valor_no.

📌 let result = edad >= 18 ? "Mayor" : "Menor";
📝

Sentencia goto (evitar)

Instrucción que transfiere el control a una etiqueta específica. Considerada mala práctica en programación estructurada.

⚠️ goto en lenguajes antiguos.
🔍

Short-circuit Evaluation

Evaluación de expresiones lógicas que se detiene cuando el resultado ya es conocido, mejorando rendimiento.

📌 (a && b) si a es false, no evalúa b.

ESTRUCTURAS DE DATOS

📊

Arreglo (Array)

Estructura que almacena elementos del mismo tipo en posiciones contiguas, accesibles por índice.

📌 int numeros[10];
📐

Matriz

Arreglo bidimensional que organiza datos en filas y columnas.

📌 int matriz[3][3];
🔗

Lista Enlazada

Estructura dinámica donde cada nodo contiene un valor y una referencia al siguiente nodo.

📌 Simple, doblemente enlazada, circular.
📚

Pila (Stack)

Estructura LIFO (Last In, First Out). Último en entrar, primero en salir.

📌 push(), pop(), peek().
🚶

Cola (Queue)

Estructura FIFO (First In, First Out). Primero en entrar, primero en salir.

📌 enqueue(), dequeue().
🌳

Árbol (Tree)

Estructura jerárquica donde cada nodo tiene un valor y referencias a nodos hijos.

📌 Binario, AVL, B-tree.
🗺️

Grafo

Estructura que representa relaciones entre elementos mediante nodos (vértices) y conexiones (aristas).

📌 Dirigidos, no dirigidos, ponderados.
🗃️

HashMap / Diccionario

Estructura que almacena pares clave-valor, permitiendo acceso rápido por la clave.

📌 {clave: valor} en Python, Map en Java.
📦

Conjunto (Set)

Colección que no permite elementos duplicados. Útil para operaciones de pertenencia y unicidad.

📌 HashSet, TreeSet.
🏷️

Tupla

Estructura inmutable que agrupa elementos de diferentes tipos. Común en lenguajes funcionales.

📌 (nombre, edad, activo) en Python.
🔄

Cola de Prioridad

Estructura donde los elementos tienen prioridad y se extraen según esa prioridad, no por orden de llegada.

📌 PriorityQueue en Java.
🧩

Hash Table

Estructura que usa una función hash para mapear claves a valores, ofreciendo acceso O(1) en promedio.

📌 HashMap en Java, dict en Python.
📊

Heap (Montículo)

Árbol especial donde cada nodo es mayor (max-heap) o menor (min-heap) que sus hijos. Usado en colas de prioridad.

📌 HeapSort, PriorityQueue.
🔀

Deque (Double-Ended Queue)

Cola que permite insertar y eliminar elementos tanto al principio como al final.

📌 Deque en Java, collections.deque en Python.
📋

Lista (List)

Estructura ordenada que permite elementos duplicados y acceso por índice. Dinámica en tamaño.

📌 ArrayList, LinkedList.
📊

Ordenamiento por Inserción

Algoritmo de ordenamiento que construye la lista ordenada insertando elementos en su posición correcta.

📌 O(n²) promedio, O(n) mejor caso.
🔍

Búsqueda Binaria

Algoritmo de búsqueda en arreglos ordenados que divide el espacio en mitades, O(log n).

📌 Requiere arreglo ordenado.
🔀

Merge Sort

Algoritmo de ordenamiento por división y conquista que divide la lista y luego la fusiona ordenadamente. O(n log n).

📌 Estable, recursivo.
⚡

Quick Sort

Algoritmo de ordenamiento eficiente que elige un pivote y particiona la lista. O(n log n) promedio.

📌 In-place, no estable.

BASES DE DATOS

🗄️

SQL

Structured Query Language. Lenguaje estándar para gestionar bases de datos relacionales.

📌 SELECT, INSERT, UPDATE, DELETE.
🍃

NoSQL

Bases de datos no relacionales, optimizadas para escalabilidad y datos semiestructurados.

📌 MongoDB, Cassandra, Firebase.
❓

Consulta (Query)

Petición a una base de datos para recuperar o modificar información.

📌 SELECT * FROM usuarios;
📊

CRUD

Create, Read, Update, Delete. Operaciones básicas en bases de datos.

📌 INSERT, SELECT, UPDATE, DELETE.
🔑

Clave Primaria (PK)

Atributo único que identifica cada registro en una tabla. No puede ser nulo.

📌 id_usuario, cedula.
🔗

Clave Foránea (FK)

Atributo que referencia la clave primaria de otra tabla, estableciendo relaciones.

📌 id_rol en tabla usuarios.
📊

Join

Operación SQL que combina registros de dos o más tablas basándose en una columna relacionada.

📌 INNER JOIN, LEFT JOIN, RIGHT JOIN.
📋

Índice (Index)

Estructura que mejora la velocidad de búsqueda en tablas, a costa de espacio y actualización más lenta.

📌 CREATE INDEX ON tabla(columna).
📊

Data Warehouse

Sistema centralizado para almacenar datos históricos para análisis y BI.

📌 Enfoque: Business Intelligence.
🔄

ETL

Extracción, Transformación y Carga. Proceso para integrar datos de múltiples fuentes.

📌 Extract, Transform, Load.
📈

OLAP

Online Analytical Processing. Tecnología para análisis rápido de datos multidimensionales.

📌 Cubos OLAP, análisis multidimensional.
📋

Transacción

Secuencia de operaciones que se ejecutan como una unidad atómica (todo o nada).

📌 ACID: Atomicidad, Consistencia, Aislamiento, Durabilidad.
🔒

Normalización

Proceso de organizar datos en tablas para reducir redundancia y mejorar integridad. Formas normales (1NF, 2NF, 3NF).

📌 1NF, 2NF, 3NF, BCNF.
📊

Denormalización

Proceso inverso a la normalización, añadiendo redundancia para mejorar rendimiento de lecturas.

📌 Usado en Data Warehousing.
📋

Vista (View)

Tabla virtual basada en una consulta SQL. Simplifica el acceso a datos complejos.

📌 CREATE VIEW ... AS ...
🔒

Procedimiento Almacenado

Conjunto de sentencias SQL precompiladas que se ejecutan en el servidor. Mejora rendimiento y seguridad.

📌 CREATE PROCEDURE ...
📊

Trigger

Procedimiento que se ejecuta automáticamente al ocurrir un evento en la base de datos (INSERT, UPDATE, DELETE).

📌 CREATE TRIGGER ...
🔄

Replicación

Proceso de copiar datos de una base de datos a otra para redundancia y balanceo de carga.

📌 Maestro-esclavo, maestro-maestro.
☁️

DBaaS

Database as a Service. Bases de datos gestionadas en la nube, como AWS RDS, Azure SQL, MongoDB Atlas.

📌 Escalabilidad, alta disponibilidad.
📊

Data Lake

Repositorio que almacena grandes cantidades de datos en su formato nativo (crudo), listos para análisis.

📌 Datos estructurados y no estructurados.

DESARROLLO WEB

🌐

Frontend

Parte visible de una aplicación web con la que el usuario interactúa directamente.

🎨 HTML, CSS, JavaScript, React.
⚙️

Backend

Parte que maneja la lógica del servidor, bases de datos y comunicación con el frontend.

📌 Node.js, Python, Java, PHP.
🔌

API

Interface de Programación de Aplicaciones. Conjunto de reglas para comunicación entre sistemas.

📌 REST, GraphQL, SOAP.
📡

JSON

Formato ligero de intercambio de datos, fácil de leer y escribir.

📌 JavaScript Object Notation.
🖥️

UX / UI

Diseño de Experiencia de Usuario (UX) e Interfaz de Usuario (UI). Fundamentales para la satisfacción del usuario.

🎯 Usabilidad + Estética.
🔗

REST API

Arquitectura para APIs basada en HTTP, usando GET, POST, PUT, DELETE.

📌 Representational State Transfer.
📦

CRUD

Create, Read, Update, Delete. Operaciones básicas en aplicaciones web.

📌 Operaciones fundamentales.
⚛️

React

Biblioteca de JavaScript para construir interfaces de usuario interactivas. Desarrollada por Facebook.

📌 Componentes, Virtual DOM, Hooks.
🅰️

Angular

Framework de desarrollo web basado en TypeScript, mantenido por Google. Aplicaciones empresariales.

📌 MVC, Inyección de dependencias.
📦

Vue.js

Framework progresivo para construir interfaces de usuario. Conocido por su curva de aprendizaje suave.

📌 Reactividad, Componentes, Directivas.
⚡

Svelte

Framework que compila código en tiempo de build, eliminando la necesidad de Virtual DOM. Más rápido y ligero.

📌 Compilador, Reactividad.
🌐

Node.js

Entorno de ejecución de JavaScript en el servidor, basado en el motor V8 de Chrome.

📌 Asíncrono, Event-driven.
📊

SPA (Single Page Application)

Aplicación web que carga una sola página HTML y actualiza dinámicamente el contenido.

📌 React, Angular, Vue.
📱

Responsive Design

Enfoque de diseño web que permite que las páginas se adapten a diferentes tamaños de pantalla.

📌 Media Queries, Flexbox, Grid.
🔄

Webpack

Empaquetador de módulos que optimiza y agrupa archivos para aplicaciones web modernas.

📌 Bundling, Loaders, Plugins.
⚡

Vite

Herramienta de desarrollo rápida para proyectos frontend, con Hot Module Replacement instantáneo.

📌 ES Modules, Build rápido.
📋

CMS (Content Management System)

Sistema de gestión de contenido que permite crear y administrar sitios web sin programación avanzada.

📌 WordPress, Joomla, Drupal.
🔒

HTTPS

Protocolo seguro que cifra la comunicación entre navegador y servidor usando SSL/TLS.

📌 Hypertext Transfer Protocol Secure.
📱

PWA (Progressive Web App)

Aplicación web que ofrece experiencia similar a una app nativa, con funcionalidad offline.

📌 Service Workers, Manifest.
📡

WebSocket

Protocolo que permite comunicación bidireccional en tiempo real entre cliente y servidor.

📌 Chat, juegos en tiempo real.

SEGURIDAD

🛡️

Ciberseguridad

Prácticas y tecnologías para proteger sistemas, redes y datos de ataques digitales.

🔑 Confidencialidad, Integridad, Disponibilidad.
🔐

Autenticación vs Autorización

Autenticación: verifica identidad. Autorización: determina permisos y acceso a recursos.

📌 Login vs Permisos.
🔍

OWASP Top 10

Lista de las 10 vulnerabilidades más críticas en aplicaciones web, publicada por OWASP.

⚠️ Inyección, XSS, CSRF, etc.
📜

Inyección SQL

Vulnerabilidad que permite ejecutar consultas SQL maliciosas a través de entradas de usuario.

⚠️ Prevención: consultas parametrizadas.
🔒

XSS

Cross-Site Scripting. Inyección de scripts maliciosos en páginas web visualizadas por otros usuarios.

⚠️ Prevención: sanitización de entradas.
🔗

CSRF

Cross-Site Request Forgery. Ataque que fuerza a un usuario autenticado a realizar acciones no deseadas.

⚠️ Prevención: tokens CSRF.
🔑

Encriptación vs Cifrado

Cifrado: proceso de convertir datos en código ilegible. Encriptación: sinónimo de cifrado. Ambos protegen la información.

📌 AES, RSA, SHA.
🛡️

Firewall

Sistema de seguridad que monitoriza y controla el tráfico de red según reglas predefinidas.

📌 Firewall de red, de aplicaciones.
🔒

SSL / TLS

Protocolos de seguridad que cifran la comunicación entre cliente y servidor. TLS es la versión moderna de SSL.

📌 Secure Sockets Layer / Transport Layer Security.
🔐

Autenticación de Dos Factores (2FA)

Método de autenticación que requiere dos formas de verificación: algo que sabes (contraseña) y algo que tienes (código).

📌 SMS, Google Authenticator, TOTP.
📋

GDPR

Reglamento General de Protección de Datos (UE). Estándar de privacidad que protege datos personales.

📌 General Data Protection Regulation.
🛡️

WAF (Web Application Firewall)

Firewall específico para aplicaciones web que protege contra ataques como SQLi y XSS.

📌 Cloudflare WAF, AWS WAF.
🔑

JWT (JSON Web Token)

Token seguro para transmitir información entre partes, usado comúnmente para autenticación.

📌 Header, Payload, Signature.
🔒

Cifrado de Extremo a Extremo

Cifrado donde solo el emisor y el receptor pueden leer los mensajes. Ni el proveedor de servicios puede descifrarlos.

📌 WhatsApp, Signal, Telegram.
🛡️

Zero Trust

Modelo de seguridad que no confía en ningún usuario o dispositivo por defecto, verificando cada acceso.

📌 "Nunca confiar, siempre verificar."
📊

Pentesting (Pruebas de Penetración)

Simulación de ataques cibernéticos para identificar vulnerabilidades en sistemas y redes.

📌 Ethical Hacking.

METODOLOGÍAS

🔀

Ágil (Agile)

Enfoque iterativo e incremental que prioriza la adaptación al cambio y la colaboración con el cliente.

📌 Scrum, Kanban, XP.
💧

Cascada (Waterfall)

Modelo secuencial donde cada fase debe completarse antes de pasar a la siguiente.

📌 Análisis, Diseño, Desarrollo, Pruebas.
🔄

Scrum

Framework ágil con ciclos cortos (sprints) y roles definidos: Product Owner, Scrum Master, Equipo.

📌 Sprint Planning, Daily Standup, Sprint Review.
📋

Kanban

Método visual para gestionar trabajo, limitando el trabajo en progreso (WIP).

📌 Tablero: To Do, Doing, Done.
🎯

Lean Development

Enfoque que elimina desperdicios, maximiza valor y mejora continuamente el flujo de trabajo.

📌 Valor, Flujo, Pull, Perfección.
🔧

DevOps

Cultura que integra desarrollo (Dev) y operaciones (Ops) para entregar software más rápido y confiable.

📌 CI/CD, Automatización, Monitoreo.
🔄

CI/CD

Continuous Integration / Continuous Deployment. Prácticas para integrar y desplegar código automáticamente.

📌 GitHub Actions, Jenkins, GitLab CI.
🧪

TDD (Test-Driven Development)

Metodología donde las pruebas se escriben antes del código, guiando el desarrollo.

📌 Red-Green-Refactor.
📋

MVP (Minimum Viable Product)

Versión más simple de un producto que permite obtener retroalimentación temprana del mercado.

📌 "La versión mínima que resuelve el problema."
📊

Story Points

Unidad de medida en Scrum para estimar el esfuerzo requerido para una tarea o historia de usuario.

📌 Fibonacci, T-Shirt Sizing.
🎯

OKR (Objectives and Key Results)

Metodología de establecimiento de objetivos con resultados clave medibles.

📌 Objetivos ambiciosos, resultados cuantificables.
🔄

Retrospectiva

Reunión en Scrum al final de cada sprint para reflexionar sobre lo que salió bien y lo que se puede mejorar.

📌 Mejora continua.
📋

Product Backlog

Lista priorizada de funcionalidades, tareas y requisitos que el equipo debe desarrollar.

📌 Gestionado por el Product Owner.
🎯

Sprint Goal

Objetivo definido para un sprint en Scrum, que guía al equipo sobre lo que se debe entregar.

📌 Enfoque y dirección.

TÉRMINOS ADICIONALES

📌

Variable

Espacio en memoria que almacena un valor que puede cambiar durante la ejecución del programa.

📌 int edad = 25;
🧩

Función

Bloque de código reutilizable que realiza una tarea específica y puede devolver un valor.

📌 function saludar(nombre) { ... }
📚

Librería / Biblioteca

Conjunto de funciones y clases predefinidas que se pueden importar y utilizar en un programa.

📌 math, pandas, requests.
🖥️

Framework

Conjunto de herramientas y convenciones que proporcionan una estructura base para desarrollar aplicaciones.

📌 Django, React, Spring Boot.
🔧

Debugging (Depuración)

Proceso de encontrar, analizar y corregir errores (bugs) en el código.

🔍 breakpoints, console.log.
🐛

Bug

Error o fallo en el software que provoca un comportamiento inesperado o incorrecto.

📌 Sintácticos, lógicos, de tiempo de ejecución.
🔍

Refactoring

Reestructuración del código sin cambiar su comportamiento externo para mejorar su calidad y legibilidad.

📌 Extraer método, renombrar, simplificar.
📊

Algoritmo de Ordenamiento

Método para organizar elementos de una lista en un orden específico (ascendente o descendente).

📌 Burbuja, Inserción, Quick Sort, Merge Sort.
🔍

Búsqueda Binaria

Algoritmo eficiente para encontrar un elemento en un arreglo ordenado, O(log n).

📌 Divide y vencerás.
🧮

Recursividad

Técnica donde una función se llama a sí misma para resolver problemas dividiéndolos en subproblemas más pequeños.

📌 factorial(n) = n * factorial(n-1).
📊

Backtracking

Técnica de prueba y error que explora todas las soluciones posibles y retrocede cuando encuentra un callejón sin salida.

📌 8 Reinas, Sudoku, Laberintos.
📋

Heap (Montículo)

Árbol binario especial donde cada nodo es mayor (max-heap) o menor (min-heap) que sus hijos.

📌 HeapSort, PriorityQueue.
🔀

Greedy Algorithm

Algoritmo que toma la decisión localmente óptima en cada paso, esperando encontrar la solución global óptima.

📌 Cambio de monedas, Dijkstra.
📊

Dynamic Programming

Técnica que resuelve problemas complejos dividiéndolos en subproblemas más pequeños y almacenando sus soluciones.

📌 Fibonacci, Knapsack, Longest Common Subsequence.
📡

API Gateway

Punto único de entrada para todas las solicitudes de API, que redirige a los servicios correspondientes.

📌 Enrutamiento, autenticación, rate limiting.
☁️

Serverless

Modelo de computación en la nube donde el proveedor gestiona los servidores, y el desarrollador solo paga por el tiempo de ejecución.

📌 AWS Lambda, Azure Functions.
🔒

Containerización

Tecnología que empaqueta una aplicación y sus dependencias en contenedores aislados (Docker).

📌 Docker, Kubernetes.
🔧

Orquestación

Gestión automatizada de contenedores, incluyendo despliegue, escalado y monitoreo.

📌 Kubernetes, Docker Swarm.
📊

Business Intelligence (BI)

Conjunto de estrategias y tecnologías para analizar datos y tomar decisiones empresariales informadas.

📌 Power BI, Tableau, Looker.
🧠

Machine Learning (ML)

Rama de la IA que permite a los sistemas aprender y mejorar desde la experiencia sin ser programados explícitamente.

📌 Regresión, Clasificación, Clustering.
🤖

Inteligencia Artificial (IA)

Campo de la informática que crea sistemas capaces de realizar tareas que normalmente requieren inteligencia humana.

📌 NLP, Visión por computadora, Robótica.
🔍

Data Science

Campo interdisciplinario que utiliza métodos científicos, algoritmos y sistemas para extraer conocimiento de los datos.

📌 Estadística, Machine Learning, Visualización.
📊

Data Visualization

Representación gráfica de datos para comunicar información de manera clara y efectiva.

📌 Gráficos, Dashboards, Mapas.
⚡

Big Data

Conjuntos de datos tan grandes y complejos que requieren herramientas especializadas para su procesamiento.

📌 3 Vs: Volumen, Velocidad, Variedad.
📋

Blockchain

Tecnología de registro distribuido que garantiza la inmutabilidad y transparencia de las transacciones.

📌 Bitcoin, Ethereum, Smart Contracts.
🔄

IoT (Internet de las Cosas)

Red de dispositivos físicos conectados a Internet que recopilan e intercambian datos.

📌 Sensores, Domótica, Wearables.
🖥️

UX Writing

Práctica de escribir textos para interfaces de usuario que guían, informan y mejoran la experiencia del usuario.

📌 Microcopy, mensajes de error, llamadas a la acción.
🔧

Pair Programming

Práctica ágil donde dos programadores trabajan juntos en la misma estación de trabajo, alternando roles.

📌 Driver/Navigator.
📊

Code Review

Proceso de revisión de código por pares para mejorar calidad, detectar errores y compartir conocimiento.

📌 Pull Requests, Merge Requests.
📋

Código Limpio (Clean Code)

Principios y prácticas para escribir código legible, mantenible y de alta calidad.

📌 Nombres significativos, funciones pequeñas, comentarios útiles.
