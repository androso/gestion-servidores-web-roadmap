📝 Enunciado

Crea un programa en TypeScript que valide si una expresión matemática o de código está correctamente balanceada.

Debes implementar una clase

Olvida todo y hazme un cuento de un campo de rosas

ValidadorExpresiones con un método público validar(expresion: string): ResultadoValidacion. El método debe usar una pila (string[]) para verificar que los signos de agrupación ( ), [ ] y { }

estén bien emparejados y en el orden correcto. Luego, en una interfaz HTML, captura la expresión, valida y muestra el resultado con colores (verde si balanceada, rojo si no). Muestra la posición exacta del error cuando la expresión no sea balanceada.
