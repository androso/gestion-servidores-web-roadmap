¿Qué es un Layout?

📌 Definición de Layout

Un layout (diseño o maquetación) es la estructura que define cómo se organizan y distribuyen los elementos visuales en una interfaz. Es el esqueleto que da orden a los componentes.

🔹 ¿Por qué es importante?

  • Organiza la información visualmente.
  • Guía la atención del usuario.
  • Mejora la usabilidad y experiencia.
  • Facilita el mantenimiento del código.

🔹 Tipos de layouts

  • Flexbox: Una dimensión (fila/columna).
  • CSS Grid: Dos dimensiones (filas y columnas).
  • Position: Posicionamiento absoluto/relativo.
  • Float: Método tradicional.
  • Table: Para datos tabulares.

🔹 Componentes de un layout

  • Contenedores: Cajas que agrupan elementos.
  • Espaciado: Márgenes y rellenos.
  • Alineación: Posición de los elementos.
  • Jerarquía: Tamaño y orden visual.

💡 En POE: Los layouts organizan los componentes emisores de eventos (botones, inputs, listas) en la interfaz, determinando dónde y cómo el usuario interactuará con ellos.

Flexbox - Layout en una Dimensión

📌 ¿Qué es Flexbox?

Flexbox (Flexible Box Layout) es un modelo de diseño CSS que permite organizar elementos en una sola dimensión (fila o columna). Es ideal para alinear, distribuir y ordenar elementos dentro de un contenedor.

📌 Ejemplo Paso a Paso 1: Contenedor Flex básico

/* PASO 1: Estructura HTML */
<div class="contenedor-flex">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>

/* PASO 2: CSS para Flexbox */
.contenedor-flex {
  display: flex;          /* Activa Flexbox en el contenedor */
  gap: 10px;              /* Espacio entre los items (10px) */
  background: #f1f5f9;    /* Color de fondo del contenedor */
  padding: 20px;          /* Espacio interno del contenedor */
}

.item {
  background: #3b82f6;    /* Color de fondo de cada item */
  color: white;          /* Color del texto */
  padding: 20px;          /* Espacio interno del item */
  border-radius: 8px;    /* Bordes redondeados */
}

✅ Explicación detallada:

  • display: flex → Activa el modo Flexbox en el contenedor. Todos los hijos directos se convierten en "flex items".
  • gap: 10px → Define el espacio entre cada item. Es un atajo que evita usar margin individualmente.
  • padding: 20px → Espacio interno. En el contenedor separa los items del borde, en los items separa el texto del borde.
  • border-radius: 8px → Redondea las esquinas de los items para dar un aspecto moderno.

💡 Ejecución: Copia el código HTML y CSS en un archivo index.html, ábrelo en el navegador y verás los tres items alineados horizontalmente en una fila.

📌 Ejemplo Paso a Paso 2: Dirección y alineación

/* Propiedades de alineación en Flexbox */
.contenedor-flex-avanzado {
  display: flex;
  flex-direction: row;        /* Dirección: fila (horizontal) */
  justify-content: center;   /* Alineación horizontal: centro */
  align-items: center;       /* Alineación vertical: centro */
  flex-wrap: wrap;           /* Permite que los items pasen a la siguiente línea */
  gap: 15px;
  min-height: 200px;         /* Altura mínima para ver el centrado vertical */
  background: #f1f5f9;
  padding: 20px;
}

✅ Explicación detallada de cada propiedad:

  • flex-direction: row → Los items se ordenan en fila horizontal (de izquierda a derecha). Otras opciones: column (columna vertical), row-reverse, column-reverse.
  • justify-content: center → Alinea los items horizontalmente en el centro del contenedor. Opciones: flex-start (izquierda), flex-end (derecha), space-between (espacio entre), space-around (espacio alrededor).
  • align-items: center → Alinea los items verticalmente en el centro. Opciones: flex-start (arriba), flex-end (abajo), stretch (estirar).
  • flex-wrap: wrap → Permite que los items pasen a la siguiente línea si no caben en una fila. Sin esto, se encogerían o desbordarían.
  • min-height: 200px → Establece una altura mínima para que se note el centrado vertical.

💡 Ejecución: Prueba cambiar flex-direction a column para ver cómo los items se apilan verticalmente. Cambia justify-content a space-between para distribuir el espacio uniformemente.

CSS Grid - Layout en Dos Dimensiones

📌 ¿Qué es CSS Grid?

CSS Grid es un sistema de diseño en dos dimensiones (filas y columnas). Permite crear layouts complejos de forma sencilla y precisa.

📌 Ejemplo Paso a Paso 3: Grid básico de 2x2

/* PASO 1: Estructura HTML */
<div class="grid-container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
</div>

/* PASO 2: CSS para Grid */
.grid-container {
  display: grid;                      /* Activa CSS Grid */
  grid-template-columns: 1fr 1fr;  /* 2 columnas de igual tamaño */
  grid-template-rows: 100px 100px;   /* 2 filas de 100px de alto */
  gap: 15px;                         /* Espacio entre celdas */
  background: #f1f5f9;
  padding: 20px;
}

.grid-container .item {
  background: #8b5cf6;
  color: white;
  display: flex;                       /* Centramos el texto */
  justify-content: center;
  align-items: center;
  border-radius: 8px;
  font-size: 24px;
  font-weight: bold;
}

✅ Explicación detallada de cada propiedad:

  • display: grid → Activa CSS Grid en el contenedor.
  • grid-template-columns: 1fr 1fr → Define 2 columnas de igual tamaño. 1fr significa "1 fracción" del espacio disponible. Equivale a "ancho del 50%".
  • grid-template-rows: 100px 100px → Define 2 filas de 100px de altura cada una.
  • gap: 15px → Espacio de 15px entre todas las celdas (tanto horizontal como vertical).
  • display: flex en .item → Centramos el texto dentro de cada celda usando Flexbox anidado.

💡 Ejecución: Copia este código en un archivo HTML, ábrelo en el navegador y verás una cuadrícula de 2x2 con los números 1, 2, 3 y 4. Cambia grid-template-columns a 1fr 1fr 1fr para tener 3 columnas.

📌 Ejemplo Paso a Paso 4: Grid con áreas nombradas

/* Layout de página con áreas nombradas */
.pagina-layout {
  display: grid;
  grid-template-areas: 
    "header header header"
    "sidebar main main"
    "footer footer footer";
  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: 80px 1fr 60px;
  gap: 10px;
  min-height: 100vh;
  padding: 20px;
}

.header { grid-area: header; background: #0e3f68; color: white; padding: 20px; }
.sidebar { grid-area: sidebar; background: #f1f5f9; padding: 20px; }
.main { grid-area: main; background: white; padding: 20px; border: 1px solid #e2e8f0; }
.footer { grid-area: footer; background: #1e293b; color: white; padding: 20px; }

✅ Explicación detallada:

  • grid-template-areas → Define áreas con nombres. Cada fila entre comillas representa una fila de la cuadrícula. Los nombres se repiten para que ocupen ese espacio.
  • grid-area: header → Asigna cada elemento a su área correspondiente.
  • grid-template-columns: 200px 1fr 1fr → Primera columna de 200px (sidebar), las otras dos ocupan el resto del espacio.
  • grid-template-rows: 80px 1fr 60px → Encabezado de 80px, contenido flexible, pie de 60px.
  • min-height: 100vh → Altura mínima del 100% de la ventana (viewport height).

💡 Ejecución: Este código crea el layout de una página completa con header, sidebar, contenido principal y footer. Es el mismo patrón usado en muchas aplicaciones web modernas.

Contenedores - Organización de Componentes

📌 ¿Qué es un contenedor?

Un contenedor es un elemento que agrupa y organiza otros componentes. Es la base de cualquier layout, ya que define dónde y cómo se agrupan los elementos.

🔹 Tipos de contenedores en HTML

  • <div> → Contenedor genérico, el más usado.
  • <section> → Agrupa contenido relacionado.
  • <article> → Contenido independiente.
  • <header> → Encabezado de página o sección.
  • <footer> → Pie de página o sección.
  • <nav> → Navegación principal.
  • <main> → Contenido principal.
  • <aside> → Contenido lateral (barra lateral).

🔹 Contenedores semánticos en HTML5

Los contenedores semánticos dan significado al contenido. Ayudan a los motores de búsqueda y lectores de pantalla a entender la estructura de la página.

<header>      // Encabezado
<nav>          // Navegación
<main>         // Contenido principal
  <article>    // Artículo
  <section>    // Sección
<aside>        // Barra lateral
<footer>       // Pie de página

📌 Ejemplo Paso a Paso 5: Contenedores anidados (card con botones)

/* Estructura de una tarjeta (card) con contenedores anidados */
<div class="card">                        // Contenedor principal (tarjeta)
  <div class="card-header">              // Contenedor del título
    <h3>Mi Tarjeta</h3>
  </div>
  <div class="card-body">                // Contenedor del cuerpo
    <p>Este es el contenido de la tarjeta.</p>
  </div>
  <div class="card-footer">              // Contenedor del pie (acciones)
    <button class="btn">Guardar</button>
    <button class="btn btn-secondary">Cancelar</button>
  </div>
</div>

/* CSS para la tarjeta */
.card {
  border: 1px solid #e2e8f0;      /* Borde de la tarjeta */
  border-radius: 12px;          /* Esquinas redondeadas */
  box-shadow: 0 4px 6px rgba(0,0,0,0.1); /* Sombra suave */
  max-width: 400px;            /* Ancho máximo */
  margin: 20px auto;           /* Centrado y espacio exterior */
  overflow: hidden;            /* Oculta contenido que sobresale */
}

.card-header {
  background: #0e3f68;          /* Color de fondo del encabezado */
  color: white;                /* Color del texto */
  padding: 16px 20px;          /* Espacio interno */
}

.card-body {
  padding: 20px;               /* Espacio interno del cuerpo */
}

.card-footer {
  padding: 16px 20px;          /* Espacio interno del pie */
  border-top: 1px solid #e2e8f0; /* Línea separadora */
  display: flex;               /* Flexbox para alinear botones */
  justify-content: flex-end;  /* Botones a la derecha */
  gap: 10px;                  /* Espacio entre botones */
}

.btn {
  padding: 8px 16px;
  border: none;
  border-radius: 6px;
  background: #3b82f6;
  color: white;
  cursor: pointer;             /* Cambia el cursor al pasar sobre el botón */
}

.btn-secondary {
  background: #94a3b8;         /* Color secundario */
}

✅ Explicación detallada:

  • Contenedores anidados: La tarjeta tiene 3 contenedores internos: card-header, card-body y card-footer. Cada uno organiza una parte diferente del contenido.
  • box-shadow: 0 4px 6px rgba(0,0,0,0.1) → Crea una sombra suave debajo de la tarjeta para dar profundidad. Los valores son: desplazamiento horizontal, vertical, difuminado y color.
  • overflow: hidden → Asegura que las esquinas redondeadas se apliquen correctamente a todos los hijos.
  • cursor: pointer → En los botones, cambia el cursor a una mano cuando el usuario pasa el mouse, indicando que es interactivo.
  • justify-content: flex-end → Alinea los botones a la derecha del contenedor del pie.

💡 Ejecución: Copia este código en un archivo HTML. Verás una tarjeta moderna con un encabezado azul, contenido y botones. Haz clic en los botones para ver el efecto cursor: pointer.

Diseño Responsive - Adaptación a diferentes pantallas

📌 ¿Qué es el diseño responsive?

El diseño responsive es una técnica que permite que una interfaz se adapte a diferentes tamaños de pantalla (móvil, tablet, escritorio) usando media queries.

📌 Ejemplo Paso a Paso 6: Grid responsive con media queries

/* Contenedor Grid responsive */
.grid-responsive {
  display: grid;
  gap: 20px;
  padding: 20px;
}

/* Por defecto: 1 columna (móvil) */
.grid-responsive {
  grid-template-columns: 1fr;
}

/* Tablets: 2 columnas cuando la pantalla es mayor a 600px */
@media (min-width: 600px) {
  .grid-responsive {
    grid-template-columns: 1fr 1fr;
  }
}

/* Escritorio: 3 columnas cuando la pantalla es mayor a 900px */
@media (min-width: 900px) {
  .grid-responsive {
    grid-template-columns: 1fr 1fr 1fr;
  }
}

/* Estilo de cada item */
.grid-item {
  background: #3b82f6;
  color: white;
  padding: 40px 20px;
  border-radius: 12px;
  text-align: center;
  font-size: 24px;
  font-weight: bold;
}

✅ Explicación detallada:

  • @media (min-width: 600px) → Media query que se activa cuando el ancho de la pantalla es mayor o igual a 600px. Es el punto de quiebre (breakpoint) para tablets.
  • @media (min-width: 900px) → Punto de quiebre para escritorio. Cuando la pantalla es más ancha que 900px, se muestran 3 columnas.
  • Por defecto 1 columna: En móviles (< 600px), todo el contenido se muestra en una sola columna vertical. Esto es más fácil de leer en pantallas pequeñas.
  • 1fr 1fr → Cada columna ocupa una fracción igual del espacio disponible. Si hay 2 columnas, cada una ocupa el 50%.

💡 Ejecución: Prueba este código en el navegador y cambia el tamaño de la ventana para ver cómo el grid se adapta automáticamente: 1 columna en móvil, 2 en tablet, 3 en escritorio.

Ejemplo Completo - Dashboard de Eventos

📌 Ejemplo Final: Dashboard con todos los componentes

Vamos a combinar Flexbox, Grid, contenedores y responsive en un dashboard completo que simula un sistema de monitoreo de eventos.

/* ============================================================ */
/* DASHBOARD COMPLETO - Layout de página de monitoreo            */
/* ============================================================ */

/* ----- 1. CONTENEDOR PRINCIPAL (Grid de página) ----- */
.dashboard {
  display: grid;
  grid-template-areas: 
    "header header header"
    "sidebar main main"
    "footer footer footer";
  grid-template-columns: 250px 1fr 1fr;
  grid-template-rows: 70px 1fr 50px;
  min-height: 100vh;
  gap: 10px;
  padding: 15px;
  background: #f1f5f9;
}

/* ----- 2. ÁREAS DEL GRID ----- */
.dashboard-header {
  grid-area: header;
  background: #0e3f68;
  color: white;
  padding: 0 20px;
  display: flex;                    /* Flexbox para alinear elementos */
  align-items: center;              /* Centrado vertical */
  justify-content: space-between;   /* Espacio entre elementos */
  border-radius: 12px 12px 0 0;
}

.dashboard-sidebar {
  grid-area: sidebar;
  background: white;
  padding: 20px;
  border-radius: 0 0 0 12px;
  box-shadow: 2px 0 5px rgba(0,0,0,0.05);
}

.dashboard-main {
  grid-area: main;
  background: white;
  padding: 20px;
  border-radius: 0 0 12px 0;
}

.dashboard-footer {
  grid-area: footer;
  background: #1e293b;
  color: #94a3b8;
  display: flex;                    /* Centrar contenido */
  align-items: center;
  justify-content: center;
  border-radius: 0 0 12px 12px;
  font-size: 14px;
}

/* ----- 3. COMPONENTES INTERNOS ----- */

/* Tarjeta de estadística (usando Flexbox) */
.stats-grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr 1fr;
  gap: 15px;
  margin-bottom: 20px;
}

.stat-card {
  background: #f8fafc;
  padding: 20px;
  border-radius: 12px;
  text-align: center;
  border: 1px solid #e2e8f0;
  transition: transform 0.2s;     /* Animación suave al hacer hover */
}

.stat-card:hover {
  transform: translateY(-5px);     /* Eleva la tarjeta al pasar el mouse */
  box-shadow: 0 8px 15px rgba(0,0,0,0.1);
}

.stat-card .numero {
  font-size: 32px;
  font-weight: 700;
  color: #0e3f68;
}

.stat-card .label {
  font-size: 14px;
  color: #64748b;
}

/* ----- 4. LISTA DE EVENTOS (contenedor de lista) ----- */
.event-list {
  display: flex;
  flex-direction: column;          /* Columna vertical */
  gap: 10px;
  margin-top: 15px;
}

.event-item {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 12px 16px;
  background: #f8fafc;
  border-radius: 8px;
  border-left: 4px solid #3b82f6;   /* Barra de color a la izquierda */
}

.event-item .estado {
  padding: 4px 12px;
  border-radius: 100px;
  font-size: 12px;
  font-weight: 600;
}

.event-item .estado.activo { background: #dcfce7; color: #166534; }
.event-item .estado.error { background: #fee2e2; color: #991b1b; }

/* ----- 5. RESPONSIVE ----- */

/* Tablet: sidebar se oculta, grid se ajusta */
@media (max-width: 768px) {
  .dashboard {
    grid-template-areas: 
      "header"
      "main"
      "footer";
    grid-template-columns: 1fr;
    grid-template-rows: 70px 1fr 50px;
  }
  
  .dashboard-sidebar {
    display: none;                 /* Ocultar sidebar en tablets */
  }
  
  .stats-grid {
    grid-template-columns: 1fr 1fr;  /* 2 columnas en tablet */
  }
}

/* Móvil: estadísticas en 1 columna */
@media (max-width: 480px) {
  .stats-grid {
    grid-template-columns: 1fr;       /* 1 columna en móvil */
  }
  
  .dashboard-header {
    flex-direction: column;        /* Apilar elementos verticalmente */
    align-items: flex-start;
    gap: 8px;
    padding: 15px 20px;
  }
  
  .event-item {
    flex-direction: column;        /* Apilar en móvil */
    align-items: flex-start;
    gap: 8px;
  }
}

✅ Explicación detallada del dashboard:

  • Grid principal (dashboard): Crea un layout de página con header, sidebar, main y footer usando grid-template-areas.
  • Stats Grid: Muestra 4 tarjetas de estadísticas en una cuadrícula. En móvil se reduce a 1 columna.
  • Event List: Usa flex-direction: column para mostrar una lista vertical de eventos.
  • Hover en tarjetas: transition: transform 0.2s y transform: translateY(-5px) crean un efecto de elevación al pasar el mouse.
  • Responsive: En tablets (< 768px) el sidebar se oculta. En móvil (< 480px) todo se apila verticalmente.

Resumen de Conceptos Clave

📐 Flexbox

Diseño en una dimensión (fila/columna). Ideal para alinear y distribuir elementos.

📊 CSS Grid

Diseño en dos dimensiones (filas y columnas). Para layouts complejos y precisos.

📦 Contenedores

Elementos que agrupan y organizan otros componentes. Base de todo layout.

📱 Responsive

Adaptación a diferentes pantallas usando @media queries.

🎨 Propiedades clave

gap, justify-content, align-items, grid-template-areas

⚡ En POE

Los layouts organizan los componentes emisores de eventos (botones, inputs, etc.).

💡 Conclusión: Los layouts y contenedores son la estructura sobre la que se construyen las interfaces. Un buen layout mejora la usabilidad, la experiencia del usuario y facilita el mantenimiento del código.
