Contexto

La Biblioteca Central de la Universidad de Oriente necesita un Sistema de Gestión de Préstamos de Libros para que los estudiantes puedan:

  • Visualizar el catálogo de libros disponibles
  • Solicitar préstamos de libros
  • Devolver libros
  • Marcar libros como favoritos
  • Filtrar libros por categoría o autor
  • Recibir notificaciones en tiempo real (simuladas)

💡 Enfoque: El sistema debe ser construido usando TypeScript con un enfoque de Programación Orientada a Eventos utilizando EventEmitter.

📌

Requisitos del Sistema

PARTE 1

Interfaces y Modelos

1.5 PUNTOS

Define una interfaz Libro con las siguientes propiedades:

Propiedad Tipo Descripción Obligatorio
id number Identificador único Sí
titulo string Título del libro Sí
autor string Autor del libro Sí
categoria string Categoría del libro Sí
anio number Año de publicación Sí
disponible boolean Disponibilidad para préstamo Sí
ejemplares number Cantidad de ejemplares disponibles Sí
esFavorito boolean Indicador de favorito Sí

1.1 (0.5 pts) Define la interfaz Libro.

1.2 (0.5 pts) Define un tipo unión llamado CategoriaLibro con los valores: "CIENCIA", "LITERATURA", "HISTORIA", "TECNOLOGIA", "ARTE".

1.3 (0.5 pts) Modifica la interfaz Libro para que la propiedad categoria use el tipo unión CategoriaLibro.

PARTE 2

Clase Emisora de Eventos

2.5 PUNTOS

2.1 (1.0 pts) Crea una clase Biblioteca que extienda de EventEmitter con un arreglo privado libros: Libro[] y un contador _idCounter: number = 1.

2.2 (1.0 pts) Implementa agregarLibro(libro: Omit<Libro, 'id' | 'disponible' | 'esFavorito'>): void que emita "libroAgregado".

2.3 (0.5 pts) Implementa solicitarPrestamo(id: number): void que emita "prestamoExitoso" o "noDisponible".

2.4 (0.5 pts) Implementa devolverLibro(id: number): void que emita "devolucionExitosa".

PARTE 3

Clases Oyentes

2.0 PUNTOS

3.1 (1.0 pts) Crea una clase NotificadorBiblioteca con métodos para mostrar mensajes en consola:

  • notificarNuevoLibro(libro: Libro)
  • notificarPrestamo(libro: Libro)
  • notificarNoDisponible(libro: Libro)
  • notificarDevolucion(libro: Libro)

3.2 (1.0 pts) Crea una clase GestorUIBiblioteca con métodos para manejar la interfaz:

  • renderizarLibros(libros: Libro[]): void
  • actualizarContador(libros: Libro[]): void
  • mostrarMensaje(mensaje: string, tipo: 'exito' | 'error' | 'info'): void
PARTE 4

Suscripciones y Conexiones

2.0 PUNTOS

4.1 (1.0 pts) En el archivo app.ts, instancia:

  • Biblioteca (emisor)
  • NotificadorBiblioteca (oyente de consola)
  • GestorUIBiblioteca (oyente de interfaz)

4.2 (1.0 pts) Registra todas las suscripciones usando .on() para los eventos:

  • "libroAgregado" → Notificador + GestorUI
  • "prestamoExitoso" → Notificador + GestorUI
  • "noDisponible" → Notificador + GestorUI
  • "devolucionExitosa" → Notificador + GestorUI
PARTE 5

Interfaz Gráfica y DOM

2.0 PUNTOS

5.1 (1.0 pts) Completa el index.html para que contenga:

  • Formulario: Título, Autor, Categoría (select), Ejemplares (number), Año (number)
  • Contenedor para mostrar los libros
  • Contador con total y disponibles
  • Área de mensajes para notificaciones
  • Filtros: Select por categoría, botones de orden

5.2 (1.0 pts) Implementa la lógica del DOM en TypeScript para:

  • Agregar libro desde el formulario
  • Solicitar préstamo desde cada tarjeta
  • Devolver desde cada tarjeta
  • Marcar/Desmarcar favorito
  • Filtrar por categoría
  • Ordenar por título y por autor
  • Mostrar solo disponibles

Notas Importantes

  1. El código debe compilar sin errores con npx tsc.
  2. Todos los eventos deben ser manejados por los oyentes correspondientes.
  3. La interfaz debe actualizarse en tiempo real al agregar, prestar, devolver o marcar favoritos.
  4. Los mensajes de consola deben aparecer según lo especificado.
  5. El filtro por categoría debe funcionar correctamente.
  6. Los botones de ordenar deben ordenar según corresponda.
  7. El botón "Solo Disponibles" debe mostrar solo los libros con ejemplares disponibles.
